# 台股學習站

每個交易日收盤後，GitHub 會自動抓取**全部上市、上櫃股票與 ETF** 的資料、計算指標，產生可以用手機看的互動報告。首頁可以像券商 App 一樣用代號或名稱搜尋。

> 僅供學習參考，不構成投資建議。

## 怎麼用

- **搜尋**：在首頁輸入代號（例如 `2330`）或名稱（例如 `台積`），點結果就能看報告。
- **自選股**：在個股頁按「☆ 加入自選」，首頁就會顯示。自選清單記在你自己的手機或電腦上。
- **智慧選股**：首頁點「智慧選股」。有 30 多個一鍵策略（技術面、籌碼面、基本面），每個技術面策略都附過去兩年的回測表現；也能自己組合 80 多種條件（MACD、KD、成交量、股本、三大法人、融資融券、千張大戶、月營收、本益比、殖利率、EPS、ROE…），並儲存成自己的策略。另有綜合評分（技術、籌碼、基本面、風險）、RS 強度排名、強勢產業、大師選股法（葛拉漢、巴菲特、彼得林區、神奇公式、IBD），以及「排除地雷股」。
- **回測實驗室**：首頁點「回測實驗室」。選股票和買賣規則（均線、MACD、KD、RSI、突破、爆量、布林、停損停利…），用過去兩年的股價模擬，會扣手續費和證交稅；也能一次比較多檔股票。
- **切換期間**：個股頁上方可以切換 1 個月、3 個月、6 個月或全部。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `stocks.txt` | 預設自選股（第一次打開網站時首頁顯示的股票） |
| `tw_stock_report.py` | 抓清單、下載股價、計算指標、產生資料的 Python 程式 |
| `fundamentals.py` | 籌碼面、基本面資料（三大法人、融資融券、月營收、財報、本益比、大戶持股） |
| `state/` | 每天累積的資料（重大訊息、月營收、大戶持股），由 GitHub 自動更新 |
| `web/index.html` | 首頁：搜尋與自選股 |
| `web/report.html` | 個股報告頁 |
| `web/screen.html` | 智慧選股頁 |
| `web/backtest.html` | 回測實驗室 |
| `requirements.txt` | 程式需要的套件 |
| `.github/workflows/update.yml` | 告訴 GitHub 什麼時候自動執行 |

## 手動更新

到 **Actions** 分頁 → 左邊點「更新台股報告」→ 右邊按 **Run workflow**。全部台股大約需要 5～15 分鐘。

## 報告內容

- 白話分析：趨勢、股價位置、RSI、KD、成交量、風險
- K 線圖 + 週線 / 月線 / 季線 + 成交量
- RSI 與 KD 圖
- 小回測：均線策略 vs 買進持有
- 名詞小教室

## 在自己電腦上執行（選用）

```
pip install -r requirements.txt
python tw_stock_report.py --list      # 只跑自選股，比較快
python tw_stock_report.py             # 全部台股
```

跑完會自動開瀏覽器預覽，按 Ctrl+C 結束。
